# dev-unknown

An AI agent skill for developing together when requirements are still unclear.

**Small increment -> functional verification -> hardening -> repeat.**

Make assumptions explicit and learn from working behavior.
Add new unit tests during hardening, recording deferred cases as `todo: test <behavior>`.
Let what you learn shape the next increment. Proceed only when it is agreed.
